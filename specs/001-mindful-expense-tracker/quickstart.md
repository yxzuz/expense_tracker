# Quickstart: Mindful Expense Tracker – Calm Page Outline

Date: 2025-10-15  
Branch: 001-mindful-expense-tracker

## Prerequisites

- Node.js 18+

## Setup

- Install dependencies
- Initialize Tailwind v4 and PostCSS
- Enable dark mode via class on <html>

## Dev

- Start the Next.js dev server
- Visit the Dashboard route

## Build & Export

- Produce static files for deployment (Next.js static export)
- Preview exported site locally

## Notes

- Lazy-load charts on Reports to keep the initial bundle small
- Use Intl.NumberFormat for currency; user can choose currency in Settings
- Keep visuals soft and accessible; avoid clutter and distractions
